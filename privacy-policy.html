FuzzyExplore privacy policy

Last updated: [date you publish this]

FuzzyExplore is a file search tool for Windows File Explorer. It works entirely on your PC. It does not collect, store or share any personal data, and it never connects to the internet.

What the app reads, and why

  • File and folder names in the folder you search, so that it can show matching results. File contents are never read.
  • The folder shown in the active File Explorer window, so that the search starts in the right place and Enter can take that window to the result you pick.

This information stays in your PC's memory while the app runs and is discarded when you close it or after a period of inactivity.

What the app stores

A small settings file (your hotkey, folders to skip and display preferences) and, if something goes wrong, an error log. Both stay in the app's own data folder on your PC and are removed when you uninstall the Microsoft Store version.

What the app sends

Nothing. FuzzyExplore has no network access, no analytics, no telemetry, no advertising and no accounts.

Microsoft Store

If you install FuzzyExplore from the Microsoft Store, Microsoft handles downloads, updates and crash reporting under the Microsoft Privacy Statement. The developer may see aggregated, anonymous statistics that the Store provides (such as install counts).

Children

The app collects no information from anyone, including children.
